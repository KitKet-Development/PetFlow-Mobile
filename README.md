# 🐾 PetFlow

PetFlow — мобильное iOS-приложение для владельцев домашних животных, позволяющее находить ветеринарные клиники, записываться на прием и хранить информацию о питомцах.

---

# 🚀 Основной функционал MVP

## Авторизация

* Регистрация
* Вход в аккаунт
* JWT авторизация

## Питомцы

* Добавление питомца
* Редактирование информации
* Карточка питомца
* История питомца

## Ветеринарные клиники

* Список клиник
* Фильтрация и сортировка
* Детальная страница клиники
* Отзывы и прайс-лист

## Записи на прием

* Создание записи
* Выбор питомца
* Просмотр записей
* Редактирование и удаление

## Профиль пользователя

* Личная информация
* Список питомцев
* История записей

# ⚙️ Запуск iOS

Инструкция по запуску PetFlow в Xcode

Требования:

* Mac с macOS 13.0 или новее
* Xcode 15 или новее (скачать в App Store)
* iPhone или симулятор iOS 16+
* Активный аккаунт Apple ID


**Шаг 1. Установка Xcode**

* Откройте App Store на Mac
* Найдите Xcode и нажмите Установить
* Дождитесь полной загрузки — размер около 12 ГБ
* После установки откройте Xcode и примите лицензионное соглашение

**Шаг 2. Получение проекта**

Если проект передан в виде архива:

Распакуйте архив в удобную папку, например Рабочий стол/PetFlow

Если проект на GitHub:

Откройте Terminal (Finder → Программы → Утилиты → Terminal)
Введите команду:

https://github.com/ВАШ_РЕПОЗИТОРИЙ/PetFlow-Mobile.git

**Шаг 3. Открытие проекта**

* Найдите файл с расширением .xcodeproj или .xcworkspace
* Дважды кликните по нему — Xcode откроется автоматически
* Подождите пока Xcode проиндексирует файлы (прогресс-бар вверху)


**Шаг 4. Настройка подписи**

Без этого шага приложение не запустится на реальном устройстве.

В левой панели кликните на PetFlow-Mobile (синяя иконка вверху списка файлов)
Выберите вкладку Signing & Capabilities
В поле Team выберите ваш Apple ID из списка
Если Apple ID не добавлен — нажмите Add an Account и войдите

**Если увидите ошибку "Failed to register bundle identifier" — измените Bundle Identifier на уникальный, например com.yourname.petflow**

**Шаг 5. Настройка адреса сервера**

Приложение подключается к локальному серверу. Нужно указать правильный IP.

В левой панели найдите файл APIConfig.swift
Найдите строку:

**baseURL = "http://192.168.1.58:8000/api/v1"**

Замените 192.168.1.58 на IP-адрес компьютера где запущен бэкенд

Как узнать IP бэкенда:

На Mac: Системные настройки → Сеть → Wi-Fi → IP-адрес
В Terminal: введите ifconfig | grep "inet " и найдите строку вида 192.168.x.x


Важно: iPhone и компьютер с бэкендом должны быть подключены к одной Wi-Fi сети


**Шаг 6. Выбор устройства для запуска**

В верхней панели Xcode рядом с кнопкой запуска ▶ есть выпадающее меню выбора устройства.
Вариант А — Симулятор :

Нажмите на выпадающее меню
Выберите, например, iPhone 16 Pro
Симулятор запустится автоматически

Вариант Б — Реальный iPhone:

Подключите iPhone к Mac через кабель
На iPhone нажмите Доверять при появлении запроса
Выберите ваш iPhone в выпадающем меню


**Шаг 7. Запуск приложения**

Нажмите кнопку ▶ (Play) в верхнем левом углу Xcode
Xcode скомпилирует проект — это займёт 1-3 минуты при первом запуске
Приложение автоматически установится и откроется на устройстве
